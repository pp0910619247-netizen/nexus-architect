🛡 Nexus Architect — Privacy Policy

อัปเดตล่าสุด: 25 สิงหาคม 2026 · ฉบับภาษาอังกฤษแบบเต็มดูที่ repo (PRIVACY_POLICY.md)

1. หลักการหนึ่งเดียว: ข้อมูลของคุณอยู่กับคุณ

ระบบทำงาน 100% บนอุปกรณ์ของคุณ (on-device) เราไม่มี server เก็บข้อมูลผู้ใช้ ไม่มี database กลาง และไม่มี tracking

2. เราเก็บอะไร และเก็บไว้ที่ไหน

  • ความจำ AI Twin — localStorage ในเบราว์เซอร์ของคุณ · export/delete ได้ทุกเมื่อ (ปุ่ม Export/Import ในแอป, ฟังก์ชัน forget)
  • Identity — Passkey credential ID, wallet address, Google email (จาก Sign-In) → เก็บ local เท่านั้น
  • KYC-Lite — ตรวจบนเครื่องทั้งหมด · เก็บเฉพาะ SHA-256 hash ของเลขเอกสาร + คะแนน match · ไม่มีรูป/เลขบัตร/ MRZ ถูกบันทึก
  • API keys (Gemini/OpenAI) — เข้ารหัส AES-256-GCM แล้วเก็บในเครื่อง

3. สิ่งที่ถูกส่งออกภายนอก (เฉพาะเมื่อคุณใช้ฟีเจอร์นั้น)

  • Blockchain Polygon Amoy — โจทย์/โหวต/งาน ที่คุณโพสต์เป็นข้อมูล public ตามธรรมชาติของ blockchain
  • CoinGecko / Wikipedia — query ราคา/ค้นความรู้ (ไม่มีข้อมูลส่วนตัว)
  • Google Identity Services — ยืนยันตัวตน Lv.1 (JWT ตรวจฝั่ง client)
  • LLM provider (ถ้าคุณเปิดใช้ Gemini/OpenAI/Ollama) — ข้อความแชทของคุณไปยัง provider นั้น · ปิดได้ด้วย Local Brain mode

4. สิทธิ์ของคุณ

  • ลบข้อมูลทั้งหมด = ล้าง localStorage ของเว็บนี้ (หรือปุ่ม forget ใน Twin)
  • Export ความจำเป็น JSON ไฟล์ไว้ย้ายเครื่อง
  • ไม่มี account กับเรา = ไม่มีอะไรให้ "ลืม" ฝั่ง server เลย

5. Presale & Blockchain

ธุรกรรม presale/market เป็น public on-chain — address wallet ของคุณโดนเห็นได้ตามธรรมชาติของ blockchain ใช้ wallet ใหม่หากต้องการความเป็นส่วนตัวสูง

6. ติดต่อ

Open source — ตรวจสอบโค้ดได้ทุกบรรทัดที่ GitHub repo ของโปรเจกต์
