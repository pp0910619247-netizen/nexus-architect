❓ FAQ
ข้อมูลน่ารู้

คำตอบสำหรับคำถามที่คนมักถามบ่อย

AI ของคุณ offline จริงไหม? ต้องใช้เน็ตไหม? ▾

ใช่ offline จริง. โมเดล GGUF 378MB ถูกฝังใน APK แอป Android — เมื่อติดตั้งแล้ว Yuri รันด้วยเอนจิน llama.cpp บนเครื่องคุณ ไม่ต้องเชื่อม internet ไม่มีค่า API ไม่ต้องทำอะไรเพิ่ม

แล้วจะใช้ AI ที่ฉลาดกว่า / สมองใหญ่ได้ไหม? ▾

ได้มากเลย. ระบบสนับสนุนหลายค่าย: สลับไป llama-server / Ollama /.llama-server ในเครื่อง / Gemini / OpenAI / Claude / OpenRouter ได้ ดั้งนี้ตั้ง API key เองได้ เก็บด้วยเข้ารหัส AES-GCM ในเครื่อง ไม่มี server กลาง

NEX32 ฟรีเซลเป็นยังไง? อยู่บนไหน? ▾

NEX32 presale เปิดขายบน Polygon Mainnet จ่ายด้วย POL ราคาอิง Chainlink Oracle. วางขาย 500,000,000 NEX (ครึ่งหนึ่งของ total supply 1,000,000,000) ฟรีเซลถึง 31 ต.ค. 2026. เช็กราคาเรียลไทม์แล้วซื้อได้เลยในหน้า app/index.html#presale

ขุดความรู้แล้วได้เหรียญจริงไหม? ▾

ระบบ reward ตาม Whitepaper v1.1: การ์ดความรู้ของคุณจะบันทึก reward_nex (difficulty 1–10 ≈ 10 ถึง 1,000+ NEX) จาก Mining Pool 300M. บันทึกในคลังที่เว็บและแอปใช้ร่วมกัน ลิงก์กับเหรียญ NEX32 บน Polygon

ข้อมูลของฉันปลอดภัยไหม? ▾

ทุกอย่างทำงานบนอุปกรณ์คุณ. KYC ประมวลผลบนเครื่อง (ไม่มีข้อมูลส่งไป server ภายนอก) บทสนทนา + key เก็บในเครื่อง เข้ารหัส AES-GCM. White-paper ให้ตรวจสอบโค้ดได้เต็มที่เพราะ open source (MIT)

ติดต่อทีมได้ยังไง? ▾

เข้าร่วม Telegram group ติดตามบน X/Twitter หรือหน้า Facebook ได้เลย — ทุกอย่างโปร่งใส open source บน GitHub
