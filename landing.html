📄 Whitepaper
Nexus Architect คืออะไร

ทำความเข้าใจโปรเจกต์ทั้งหมดใน 3 นาที

Nexus Architect คือระบบนิเวศที่สร้าง "AI คู่ชีวิต" ที่ทำงานบนอุปกรณ์ของคุณเอง — ไม่ต้องพึ่ง Cloud ไม่ต้องเสียค่า API ไม่ต้องกลัวข้อมูลรั่ว

ทุกคนมี Digital Twin — AI ที่เรียนรู้จากข้อความสนทนาของคุณ จดจำความชอบ ความสนใจ และช่วยคิด ช่วยทำในแบบที่คุณต้องการ ทั้งหมดทำงานบนเบราว์เซอร์ของคุณเอง

ระบบ The Mountain ให้ชุมชนเสนอและโหวตปัญหาที่อยากให้ AI ช่วยแก้ — งานแบบ เจ้าและลูกจ้าง สร้างระบบนิเวศที่ทุกคนมีส่วนร่วมได้จริง

เป้าหมายของเรา: สร้างระบบนิเวศที่ทุกคนมี AI คู่ชีวิตส่วนตัว และมีส่วนร่วมในชุมชนที่โปร่งใส — เริ่มจากชุมชนเล็กๆ สู่การเปลี่ยนแปลงระดับโลก

ทุกอย่างเป็น Open Source ภายใต้ MIT License — ใครก็สามารถตรวจสอบ แก้ไข และสร้างต่อได้

💡 คุณสมบัติหลัก

  • AI Twin — AI ที่ทำงานบนเบราว์เซอร์ ไม่ต้องติดตั้ง ไม่ต้องมี API key
  • The Mountain — เสนอและโหวตปัญหาชุมชน
  • Escrow Jobs — จ้างงานปลอดภัย ปลดล็อกเมื่องานเสร็จ
  • KYC On-Device — ยืนยันตัวตนบนอุปกรณ์ของคุณ ข้อมูลไม่ไปไหน
  • Private by Design — ไม่มี server กลาง ไม่มีโฆษณา
  • Open Source — MIT License ตรวจสอบได้ทุกอย่าง

ระบบนิเวศ ทั้งหมด

ทุกฟีเจอร์ถูกออกแบบมาเพื่อทำงานร่วมกัน

🧠

AI Twin บนอุปกรณ์ของคุณ

ใช้ WebGPU/WASM รันโมเดล AI บนเบราว์เซอร์ของคุณเอง — ไม่ต้องส่งข้อมูลไป Cloud ใดๆ เรียนรู้จากบทสนทนาและปรับตัวตามคุณ

🏔

The Mountain — เสนอปัญหา

ทุกคนเสนอปัญหาให้ชุมชนโหวตได้ ข้อมูลเปิดเผย ตรวจสอบได้ทุกขั้นตอน — ปัญหาที่มีคะแนนสูงสุดจะอยู่รอด

💼

งาน Escrow ปลอดภัย

จ้างงานแบบมีสัญญาผูกพัน — เงินถูกล็อกไว้จนกว่างานจะเสร็จ ค่าธรรมเนียม 10% กระจายให้ชุมชนอัตโนมัติ

🔐

ยืนยันตัวตนแบบปลอดภัย

KYC ทั้งหมดทำงานบนอุปกรณ์ของคุณ — ตรวจบัตรประชาชน หนังสือเดินทาง ตรวจจับการกะพริบตา ไม่มีข้อมูลไหนถูกส่งไป server ภายนอก

❓ คำถามที่พบบ่อย
FAQ

คำตอบสำหรับคำถามที่คนมักถามบ่อย

Nexus Architect คืออะไร? ▾

ระบบ AI ที่ทำงานบนอุปกรณ์ของคุณเอง (ไม่พึ่ง Cloud) — รวมการโหวตปัญหา จ้างงาน และการมีส่วนร่วมในชุมชนไว้ที่เดียว

AI Twin ทำงานยังไง? ต้องมี API key ไหม? ▾

AI ทำงานบนเบราว์เซอร์ของคุณเองผ่าน WebGPU/WASM ไม่ต้องมี API key ไม่ต้องเสียค่า Cloud ข้อมูลไม่ถูกส่งไปไหนเลย

The Mountain คืออะไร? ▾

ระบบเสนอปัญหาของชุมชน — ทุกคนเสนอปัญหา ผู้อื่นโหวตได้ ปัญหาที่มีคะแนนสูงสุดจะอยู่รอด ปัญหาที่ไม่ผ่านจะถูกคัดออก

AI Twin APK จะมีเมื่อไหร่? ▾

แผน Q4 2025 — สร้าง Android APK ก่อน (ติดตั้งตรง ไม่ผ่าน Play Store) เมื่อมีงบประมาณจาก grant จะลง Play Store ต่อไป

ข้อมูลของฉันปลอดภัยไหม? ▾

ทุกอย่างทำงานบนอุปกรณ์ของคุณ — AI ไม่ส่งข้อมูลไป Cloud, KYC ประมวลผลบนเครื่องของคุณ, ข้อมูลเก็บใน localStorage ไม่มี server กลาง

ติดต่อทีมงานได้ยังไง? ▾

เข้าร่วม Telegram group หรือติดตามบน X/Twitter — ทุกอย่างโปร่งใสเพราะเป็น open source บน GitHub

พร้อมเริ่มต้น ไปด้วยกัน?
