📄 Whitepaper
Nexus Architect คืออะไร

ทำความเข้าใจโปรเจกต์ทั้งหมดใน 3 นาที

Nexus Architect คือระบบนิเวศที่สร้าง "AI คู่ชีวิต" ที่ทำงานบนอุปกรณ์ของคุณเอง — ไม่ต้องพึ่ง Cloud ไม่ต้องเสียค่า API ไม่ต้องกลัวข้อมูลรั่ว

ทุกคนมี Digital Twin — AI ที่เรียนรู้จากข้อความสนทนาของคุณ จดจำความชอบ ความสนใจ และช่วยคิด ช่วยทำในแบบที่คุณต้องการ ทั้งหมดทำงานบนเบราว์เซอร์ของคุณเอง

บน Polygon Blockchain ปัญหาของชุมชนถูกเสนอ โหวต และคัดออกทุกวัน ผ่านระบบ The Mountain งาน freelancing ใช้ Smart Contract Escrow ที่ปลอดภัย และ Token NEX เป็นรางวัลสำหรับผู้มีส่วนร่วม

เป้าหมายของเรา: สร้างระบบนิเวศที่ AI + Blockchain ทำงานร่วมกันเพื่อแก้ปัญหาจริงของผู้คน — เริ่มจากชุมชนเล็กๆ สู่การเปลี่ยนแปลงระดับโลก

ทุกอย่างเป็น Open Source ภายใต้ MIT License — ใครก็สามารถตรวจสอบ แก้ไข และสร้างต่อได้

  • AI Twin — AI ที่ทำงานบนเบราว์เซอร์ ไม่ต้องติดตั้ง ไม่ต้องมี API key
  • The Mountain — เสนอและโหวตปัญหาชุมชนบน Blockchain
  • Escrow Jobs — จ้างงานด้วย Smart Contract ปลอดภัย 100%
  • NEX Token — รางวัลสำหรับการมีส่วนร่วมในระบบนิเวศ
  • KYC On-Device — ยืนยันตัวตนบนอุปกรณ์ของคุณ ข้อมูลไม่ไปไหน
  • Dual Presale — ซื้อ NEX ด้วย USDT หรือ POL
  • Open Source — MIT License ตรวจสอบได้ทุกอย่าง

❓ คำถามที่พบบ่อย
FAQ

คำตอบสำหรับคำถามที่คนมักถามบ่อย

Nexus Architect คืออะไร? ▾

ระบบ AI + Blockchain ที่รวม AI ที่ทำงานบนอุปกรณ์ของคุณเอง (ไม่พึ่ง Cloud) เข้ากับ Polygon Blockchain เพื่อแก้ปัญหาจริงของชุมชน — ทั้งการโหวตปัญหา จ้างงาน และให้รางวัลผ่าน Token

AI Twin ทำงานยังไง? ต้องมี API key ไหม? ▾

AI ทำงานบนเบราว์เซอร์ของคุณเองผ่าน WebGPU/WASM ใช้โมเดล Qwen2.5-1.5B ที่รันบนเครื่องของคุณ ไม่ต้องมี API key ไม่ต้องเสียค่า Cloud ข้อมูลไม่ถูกส่งไปไหนเลย

ซื้อ NEX ยังไง? ▾

ไปที่หน้า Presale เชื่อม MetaMask (Polygon Network) แล้วกด Buy จ่ายได้ทั้ง USDT (Polygon PoS) หรือ POL ขั้นต่ำ 100 NEX

Smart contract ผ่าน audit 了吗? ▾

ตอนนี้มี 35 tests ผ่านหมด内部 — แต่ยังไม่ผ่าน external audit ภายนอก แผนคือทำ Q4 2025 หลังได้ grant funding

The Mountain คืออะไร? ▾

ระบบเสนอปัญหาของชุมชนบน Blockchain — ทุกคนเสนอบทปัญหา ผู้อื่นโหวตได้ ปัญหาที่มีคะแนนสูงสุด 10 อันดับจะอยู่รอด ปัญหาที่ไม่ผ่านจะถูกคัดออกทุกวันตอนเที่ยงคืน

AI Twin APK จะมีเมื่อไหร่? ▾

แผน Q4 2025 — สร้าง Android APK ก่อน (ติดตั้งตรง ไม่ผ่าน Play Store) เมื่อมีงบประมาณจาก grant จะลง Play Store ต่อไป

ข้อมูลของฉันปลอดภัยไหม? ▾

ทุกอย่างทำงานบนอุปกรณ์ของคุณ — AI ไม่ส่งข้อมูลไป Cloud, KYC ประมวลผลบนเครื่องของคุณ, ข้อมูลเก็บใน localStorage ไม่มี server กลาง

ติดต่อทีมงานได้ยังไง? ▾

เข้าร่วม Telegram group หรือติดตามบน X/Twitter — ทุกอย่างโปร่งใส因为我เป็น open source บน GitHub
